# คลังข้อมูลตีกลับ

เว็บแอปบันทึกและรายงานสินค้าตีกลับ (returns tracker) หลายผู้ใช้ พร้อมระบบทีม สิทธิ์ผู้ใช้ และรายงานแยกหัวข้อ

สร้างด้วย [Claude](https://claude.ai) เป็น Artifact — ไฟล์ `index.html` คือซอร์สโค้ดฉบับเต็มของหน้าเว็บ (HTML/CSS/JS ไฟล์เดียว)

## ฟีเจอร์หลัก

- บันทึกรายการสินค้าตีกลับ: วันที่ เลขพัสดุ สินค้า ลูกค้า ที่อยู่ คนขาย ทีม ขนส่ง ราคา จำนวนสั่ง/ตีกลับ สาเหตุ
- แดชบอร์ดภาพรวมและกราฟสรุป
- รายงานแยกหัวข้อ: สินค้า / คนขาย / ทีม / ขนส่ง / สาเหตุ / จังหวัด / เดือน พร้อมตัวกรองช่วงเวลา ทีม และคนขาย
- ตารางรายละเอียดเต็มเมื่อดูรายงานแยกตามคนขาย
- ระบบผู้ใช้และทีม: บทบาท แอดมิน / ดูข้อมูลได้หมด / หัวหน้าทีม / พนักงานขาย — ผู้ใช้แต่ละทีมเห็นเฉพาะข้อมูลทีมตัวเอง
- เข้าสู่ระบบด้วยชื่อผู้ใช้ + รหัสผ่าน (เก็บเป็นแฮช SHA-256)
- นำเข้า/ส่งออกข้อมูลเป็น Excel (.xlsx) และสำรอง/กู้ข้อมูลเป็น JSON
- ธีมสีเหลืองพาสเทล พร้อมโลโก้และลายน้ำ

## การใช้งาน

ไฟล์นี้ถูกออกแบบมาให้รันในฐานะ [Claude Artifact](https://claude.ai) ซึ่งให้ความสามารถเพิ่มเติมผ่าน `window.claude`:

- **db** — ฐานข้อมูลที่ใช้เก็บรายการตีกลับ ผู้ใช้ และทีม (คอลเลกชัน `returns`, `appUsers`, `teams`)
- **user** — ระบุตัวตนเจ้าของ Artifact (ใช้เป็นบัญชีแอดมินสำรองเริ่มต้น)
- **downloads** — บันทึกไฟล์ Excel/JSON ที่ส่งออก
- **assets** — โลโก้ของแอป

เปิดไฟล์นี้นอก Claude Artifact (เช่น เปิดตรงในเบราว์เซอร์) จะเข้าสู่ **โหมดทดลอง** อัตโนมัติ: ใช้ข้อมูลตัวอย่างในหน่วยความจำ ไม่มีการบันทึกถาวร เหมาะสำหรับดูหน้าตา/ทดสอบ UI เท่านั้น

> ไม่มีข้อมูลลูกค้าจริงอยู่ใน repository นี้ — ข้อมูลตัวอย่าง (`SEED`) ในซอร์สโค้ดเป็นข้อมูลสมมติทั้งหมด ข้อมูลจริงทั้งหมดเก็บอยู่ในฐานข้อมูลของ Claude Artifact เท่านั้น ไม่เคยอยู่ในไฟล์นี้
